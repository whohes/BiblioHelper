# BiblioHelper — учёт книжного фонда

Настольная программа для работы с Excel-файлами книжного фонда библиотеки.
Программа открывает Excel-файл, делает его **рабочую копию** и работает только
с ней. Исходный файл никогда не изменяется.

Архитектура и план разработки согласованы в документе «BiblioHelper: архитектура (этап 1)».

## Что внутри

| Папка | Что там |
| --- | --- |
| `src/ui/` | окна программы |
| `src/core/` | рабочие копии, чтение листа фонда |
| `src/models/` | таблица книг, поиск, фильтры и сортировка |
| `src/io/` | чтение и запись Excel (OpenXLSX) |
| `src/resources/` | оформление и справка |
| `tests/` | автотесты; `tests/data/` — образцы фондов |
| `cmake/` | подключение сторонних библиотек |

## Сборка

Нужны Qt 5.15 (последняя версия Qt с поддержкой Windows 7) и CMake 3.16+.
Код совместим и с Qt 6. Сторонние библиотеки (OpenXLSX, QXlsx) скачиваются
автоматически при первой настройке, нужен интернет.

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<путь к Qt>
cmake --build build
ctest --test-dir build --output-on-failure
```

Готовая папка с программой для Windows (32 бита, Windows 7–11) собирается
автоматически в GitHub Actions: вкладка Actions → последняя сборка →
артефакт `BiblioHelper-win32`.

## Библиотеки

- [OpenXLSX](https://github.com/troldal/OpenXLSX) (BSD-3) — рабочие копии XLSX.
  Правит только изменённые ячейки, стили, автофильтр, ширины столбцов и
  другие листы остаются прежними (проверяет `tests/test_xlsx_roundtrip.cpp`).
  Новые книги дописываются строками после последней строки данных: итоги
  (`=SUM`) и автофильтр растягиваются, строка «По документам» уезжает вниз.
  Внутренние ID экземпляров хранятся в скрытом листе `_BiblioHelper`
  рабочей копии (в Excel его не видно).
- [QXlsx](https://github.com/QtExcel/QXlsx) (MIT) — новые отчёты и экспорт.
